# 项目状态

- 目标：制作一个比官方页面更易探索的全球米其林餐厅地图。
- 当前范围：必比登、1 星、2 星、3 星；客观事实字段和地图坐标。
- 当前状态：`FEASIBILITY_PILOT_ONLY`。
- 已验证：存在可复用的 MIT 许可开源快照；字段可转换为地图数据；餐厅均有名称、地点、地址、菜系、奖项、价格符号、坐标和来源 URL。
