# 首版数据范围

## 纳入

- 全球米其林指南收录的必比登与 1–3 星餐厅。
- 名称、国家、区域、城市、详细地址、菜系、荣誉、价格符号、经纬度、来源链接、快照日期。
- CSV 与 GeoJSON 两种交付格式。

## 暂不纳入

- Selected Restaurants、Green Star（可作为独立标签后续加入）。
- 餐厅评论全文、图片、菜单、预订库存。
- 精确人均消费；不同国家的价格符号不可直接横向换算。

## 验收条件

- 四类奖项均能被确定性映射。
- 每条记录均有唯一来源 URL 和合法坐标。
- 必填字段缺失率为 0。
- 数据文件可被常见地图库直接加载。

## 停止条件

- 若商业上线前无法取得足够的数据再发布依据，则不以米其林官网的全量数据库为生产数据源。
- 若抽样发现国家/城市拆分错误率超过 1%，前端先使用 `location_raw`，并替换为地理编码或人工校验流程。
